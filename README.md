# Wiki Offline — Умная Википедия без интернета

Программа для чтения офлайн-архивов Википедии в формате **ZIM** (Kiwix) с современным интерфейсом и **умным ИИ-поиском по смыслу**.

## Что умеет программа
- **Умный поиск по смыслу (ИИ):**
  - Встроенная локальная нейросеть (`multilingual-e5-small` в папке `models/`, работает полностью без интернета) понимает вопросы и описания своими словами — например:
    - *«кто написал войну и мир»* → **Война и мир** (сразу видно автора во вступлении)
    - *«почему небо голубое»* → **Диффузное излучение неба**, **Рэлеевское рассеяние**, **Небо**
    - *«самая высокая гора в мире»* → **Джомолунгма**, **Список высочайших вершин Земли**
    - *«болезнь когда не сворачивается кровь»* → **Гемофилия**
    - *«частица без массы»* → **Безмассовые частицы**, **Фотон**
  - Автоматически исправляет забытую раскладку клавиатуры (*«vjcrdf»* → **Москва**) и учитывает падежи русских слов.
  - Работает **сразу** на любом архиве (нейросеть на лету переранжирует найденные статьи за доли секунды), а при желании можно включить полную фоновую ИИ-индексацию архива с паузой и продолжением.
- **Удобный интерфейс:**
  - **Стартовая страница** с большой строкой поиска, быстрыми подсказками и карточками всех ваших энциклопедий (например, полная *Википедия* и *Физика по Википедии*).
  - **Карточка «Лучший ответ»** с первым абзацем и иллюстрацией прямо на странице результатов поиска.
  - **Закладки (Избранное)** — сохраняйте важные статьи кнопкой `☆` в верхней панели.
  - **История просмотров** — автоматически сохраняет прочитанные статьи с поиском и очисткой.
  - **Тёмная и светлая тема**, настройка масштаба текста (`A−` / `A+`), случайная статья (`🎲`).

## Как запустить
1. Откройте папку программы (`C:\Users\user\Desktop\wiki`).
2. Дважды нажмите **[start.bat](file:///C:/Users/user/Desktop/wiki/start.bat)** (или выполните `python wiki_offline.py`).
3. В браузере автоматически откроется адрес **http://127.0.0.1:8765**.
   *(Если страница уже была открыта ранее, нажмите `Ctrl+F5`, чтобы обновить интерфейс).*

## Горячие клавиши
- `/` — быстро перейти к строке поиска
- `↑` `↓` `Enter` — выбор подсказки в выпадающем списке
- `Alt+←` / `Alt+→` — назад / вперёд
- `Esc` — закрыть боковую панель или подсказки
